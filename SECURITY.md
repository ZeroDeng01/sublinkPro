# Security Policy

## Report a vulnerability

Sign in to GitHub and open the project's [Security Advisories](https://github.com/ZeroDeng01/sublinkPro/security/advisories). If GitHub displays **Report a vulnerability**, use it to send a private report. If the button is unavailable, open an [issue](https://github.com/ZeroDeng01/sublinkPro/issues) asking maintainers for a private contact and leave vulnerability details out of the issue.

In the private report, include the affected version, deployment method, impact, and relevant details. Remove live credentials, tokens, subscription links, and personal data from any attachments.

Check [Releases](https://github.com/ZeroDeng01/sublinkPro/releases) for fixes and update guidance. For instance hardening and recovery, see the [operator security guide](docs/user/security-guidelines.md).
