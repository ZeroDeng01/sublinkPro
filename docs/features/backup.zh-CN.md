# 系统备份与 WebDAV

SublinkPro 可以将现有系统备份直接上传到 WebDAV，并从远程 ZIP 备份恢复当前实例。该功能复用原有备份格式和数据库迁移流程。

## 使用方法

1. 使用管理员账号进入 **用户中心 → 系统备份**。
2. 填写 WebDAV 地址、用户名、密码或应用专用密码，以及远程目录。
3. 先点击 **测试连接**，确认账号可以读取远程目录。上传时会在需要时尝试创建缺失目录。
4. 点击 **保存设置**。
5. 可选启用 **定时备份**，并设置 5 段 Cron 表达式，例如 `0 3 * * *` 表示每天 03:00。
6. 点击 **立即备份到 WebDAV**，系统会生成 ZIP 并上传。
7. 在远程备份列表中选择一个 ZIP，确认覆盖风险后即可恢复。

WebDAV 地址示例：

```text
https://dav.example.com/remote.php/dav/files/username
```

远程目录示例：

```text
SublinkPro/backups
```

地址中不要包含用户名、密码、查询参数或锚点。缺失的远程目录会通过 WebDAV `MKCOL` 尝试逐级创建。

## 备份内容

ZIP 与右上角头像菜单中的本地系统备份使用相同内容：

- `db/`：当前数据目录；
- `template/`：模板目录；
- 不包含可重新下载的 `GeoLite2-City.mmdb`。

WebDAV 系统备份当前仅支持 SQLite。使用 MySQL 或 PostgreSQL 时，“立即备份到 WebDAV”和定时备份都会被拒绝，因为本地数据目录不包含远程数据库服务器中的业务数据。

## 定时备份

启用定时备份后，SublinkPro 会注册系统 Cron 任务，按计划生成与手动上传相同的 ZIP，并发送到已配置的 WebDAV 目录。

- 计划使用标准 5 段 Cron 表达式（`minute hour day month weekday`）。
- 保存 WebDAV 设置后会热加载定时任务，无需重启进程。
- 从备份恢复时会保留当前实例的 WebDAV 连接和定时计划设置。
- 如果上一次定时备份仍在上传，本次调度会被跳过。
- 任务中心会以 `webdav_backup` 类型展示进度。

## 恢复行为

远程恢复会先把选中的 ZIP 下载到服务器临时目录，然后复用数据库迁移任务：

- 覆盖当前业务数据；
- 恢复 ZIP 中的模板目录；
- 可选择是否恢复 AccessKey 和订阅访问日志；
- 当前实例的 JWT、加密密钥、Cloudflare Tunnel、WebDAV 设置及 SOCKS5 网关配置（含账号、监听入口与路由 Profile）会保留；
- 完成后可能需要重启实例。

恢复前请先备份当前实例。任务进度和结果可在任务中心查看。

## 安全说明

- WebDAV 设置和所有备份接口仅管理员可用，演示模式下禁用。
- WebDAV 密码使用实例的 `SUBLINK_API_ENCRYPTION_KEY` 加密保存，API 不回传明文密码。
- 备份可能包含账号数据、AccessKey、节点凭据、私钥及其他敏感内容。
- 默认要求 HTTPS。只有显式启用后才允许 HTTP；明文 HTTP 仅应在可信、隔离的内网中使用。
- 默认拒绝回环、私网和保留地址。连接可信内网 NAS 时，需要显式启用“允许访问私有网络”。
- 客户端不会跟随重定向；同源的 `MKCOL` 目录重定向可直接接受，但不会向新地址发送请求。远程文件名必须是单个 `.zip` 文件名。
- 单个远程备份的上传和下载上限为 1 GiB，WebDAV 文件列表最多显示最近 200 个 ZIP。

## 当前范围

当前版本支持手动测试、上传、列表、恢复和定时备份。暂不包含远程删除和自动保留策略。
